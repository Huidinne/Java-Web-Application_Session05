# So sánh 2 cách dùng Header/Footer

| Tiêu chí     | Cách A: Copy-paste               | Cách B: Layout Dialect |
| ------------ | -------------------------------- | ---------------------- |
| Cách làm     | Copy header/footer vào từng file | Dùng layout chung      |
| Ưu điểm      | Dễ làm, không cần cấu hình       | Tái sử dụng, code gọn  |
| Nhược điểm   | Lặp code, khó sửa                | Cần cấu hình thêm      |
| Bảo trì      | Khó (sửa nhiều file)             | Dễ (sửa 1 file)        |
| Tính mở rộng | Kém                              | Tốt                    |

Kết luận: Layout Dialect tốt hơn khi dự án lớn.


# Giải thích kỹ thuật

Layout Dialect là thư viện mở rộng của Thymeleaf, không có sẵn mặc định.
Vì vậy phải đăng ký Bean `LayoutDialect` vào `SpringTemplateEngine` thì Thymeleaf mới hiểu được các thuộc tính như `layout:decorate`, `layout:fragment`.

Nếu không đăng ký, các thẻ layout sẽ không hoạt động.
