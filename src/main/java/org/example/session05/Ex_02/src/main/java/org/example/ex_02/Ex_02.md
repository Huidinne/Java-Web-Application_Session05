# Phân tích luồng Input / Output – Bài 2

Hệ thống sử dụng mô hình MVC để hiển thị danh sách món ăn.

Khi người dùng truy cập vào đường dẫn `/bai2/dishes`, trình duyệt sẽ gửi request đến `DishController`. Controller nhận request này và gọi `DishService` để lấy danh sách món ăn.

Service sẽ tạo và trả về một `List<Dish>`. Sau đó Controller đưa danh sách này vào Model bằng `model.addAttribute("dishes", list)` và trả về view `dish-list`.

Ở phía View, Thymeleaf sẽ nhận dữ liệu từ Model và hiển thị ra giao diện. Nếu danh sách có dữ liệu thì sẽ lặp qua từng món bằng `th:each` để hiển thị. Nếu món ăn hết hàng thì sẽ hiển thị chữ "Hết hàng" và đổi màu đỏ.

Trong trường hợp danh sách rỗng hoặc null, hệ thống sẽ không hiển thị bảng mà thay vào đó hiển thị thông báo: "Hiện tại nhà hàng đang cập nhật thực đơn, vui lòng quay lại sau".

Tóm lại, dữ liệu đi từ Controller → Service → Model → View, sau đó được hiển thị lại cho người dùng.
